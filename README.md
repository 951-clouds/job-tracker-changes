# 岗位雷达：岗位搜索与变更追踪

这是一个可直接在本机运行的求职岗位应用。它从真实招聘来源采集岗位，按“来源 + 稳定岗位 ID”去重，并保存关注期间的岗位要求、截止时间和招聘状态变化。

## 真实来源

- **Remotive**：招聘平台公开 API
- **Amazon Jobs**：Amazon 官方招聘搜索接口

两个来源均在后端实时请求。公开接口没有明确提供岗位截止时间或招聘状态时，应用显示“未提供”，不会根据列表是否存在、请求失败或页面不可达来推断关闭或下架。

## 运行

环境要求：Java 17 或更高版本（需要 java 和 javac）。

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

然后打开 http://127.0.0.1:8787

首次打开且没有采集数据时，应用会提示先执行采集。数据默认保存在 data/jobtracker-state.json，筛选方案、关注记录和动态按账号隔离。

## 功能

- 岗位浏览与关键词、城市联合搜索
- 筛选方案新建、修改、删除和使用
- 关注与取消关注岗位
- Remotive 与 Amazon Jobs 真实采集
- 关注期间岗位要求、截止时间和招聘状态变更追踪
- 多用户数据隔离
